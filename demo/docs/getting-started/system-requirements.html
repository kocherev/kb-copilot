System requirements

Northstar Desk runs in a web browser. There is nothing to install on agent computers.

Supported browsers

We support the latest two versions of these browsers:

  • Google Chrome
  • Mozilla Firefox
  • Apple Safari
  • Microsoft Edge

Internet Explorer is not supported. Older browser versions may load, but we do not fix problems that only happen on them.

Screen and settings

A screen at least 1280 pixels wide is recommended for the ticket view. JavaScript and cookies must be enabled. Desktop notifications for new tickets need permission from the browser the first time you turn them on.

Network access

If your company uses a firewall or proxy, allow traffic to every subdomain of northstardesk.example over HTTPS on port 443. Live updates in the ticket list use WebSockets on the same port. When WebSockets are blocked, the ticket list falls back to refreshing every 30 seconds.
