Plan limits

This page lists the hard limits for each plan. Limits apply per workspace.

Starter limits

  • Paid seats: up to 3
  • Support email addresses: 1
  • Automation rules: 10
  • Saved macros: 25
  • API access: not included
  • Webhook endpoints: not included

Team limits

  • Paid seats: up to 50
  • Free Light agents: up to 10
  • Support email addresses: up to 10
  • Automation rules: 200
  • Saved macros: unlimited
  • API rate limit: 600 requests per minute
  • Webhook endpoints: 20

Enterprise limits

  • Paid seats: no upper limit, contracts start at 20
  • Free Light agents: unlimited
  • Support email addresses: unlimited
  • Automation rules: unlimited
  • API rate limit: 3,000 requests per minute
  • Webhook endpoints: 100

Limits on every plan

Attachments can be up to 25 MB per file. One email, including all attachments, can be up to 40 MB.
