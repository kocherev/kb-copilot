# Two-factor authentication

Two-factor authentication adds a second step to sign-in, so a stolen password alone is not enough.

## Supported methods

You can use an authenticator app that shows six-digit codes, or a hardware security key. Security keys use WebAuthn and work in every supported browser. Text message codes are not offered.

## Turn it on

Open your profile, choose Security, and select Set up two-factor authentication. Scan the code with your authenticator app or touch your security key. Northstar Desk then shows 10 backup codes. Each backup code works once, so store them somewhere safe.

## Require it for everyone

An Admin can require two-factor authentication for the whole workspace from Settings > Security. People who have not set it up are asked to do so at their next sign-in and cannot use the workspace until they finish.

## Lost your device

Sign in with one of your backup codes, then set up two-factor authentication again on the new device. If you have no backup codes left, ask an Admin to reset your two-factor authentication from Settings > Team. The Owner's two-factor authentication can only be reset by Northstar support after an identity check, which takes up to 2 business days.
