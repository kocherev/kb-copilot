# Roles and permissions

Every person in a workspace has exactly one role. The role decides what they can see and change.

## The four roles

Northstar Desk has four roles: Owner, Admin, Agent, and Light agent. A workspace always has exactly one Owner. You can have as many Admins and Agents as you have paid seats.

## Owner

The Owner manages billing, can delete the workspace, and is the only person who can transfer ownership. The Owner can also do everything an Admin can do. By default only the Owner can see invoices and change the payment method.

## Admin

Admins manage teammates, channels, integrations, security settings, and API keys. Admins cannot delete the workspace or transfer ownership. The Owner can give one or more Admins the billing permission from Settings > Team, which lets them see invoices and update payment details.

## Agent

Agents work tickets. They can send public replies, change status and priority, and use macros. Agents cannot change workspace settings. Each Agent uses one paid seat.

## Light agent

Light agents can view tickets and add internal notes, but they cannot send public replies or change a ticket's status. They are useful for engineers or managers who help behind the scenes. Light agents do not use a paid seat. The Team plan includes up to 10 Light agents, and Enterprise has no limit.

## Changing a role

An Admin changes a role from Settings > Team by opening the person's profile. The change takes effect the next time that person loads a page.
