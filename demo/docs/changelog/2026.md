# Changelog 2026

New features and changes in Northstar Desk during 2026, newest first.

## October 2026

Webhooks can now send the comment.added event when a reply or internal note is added to a ticket. Slack thread replies under a ticket alert are now saved to the ticket as internal notes.

## September 2026

The EU data region in Frankfurt is now available on every plan. Before this release it was limited to Enterprise. Existing workspaces keep the region they were created in.

## July 2026

Two-factor authentication now supports hardware security keys through WebAuthn, in addition to authenticator apps.

## May 2026

Light agents arrived. They can read tickets and add internal notes without using a paid seat. The Team plan includes up to 10 Light agents.

## March 2026

Version 1 of the API was retired on 31 March 2026. All integrations must use version 2.

## January 2026

Admins on the Team and Enterprise plans can now choose how long solved tickets wait before closing, anywhere from 1 to 28 days. The default stays at 4 days.
