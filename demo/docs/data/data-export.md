# Export your data

You can download a full copy of your workspace data at any time, on every plan.

## Who can export

The Owner and Admins can run an export. Agents and Light agents cannot.

## Run an export

Open Settings > Data > Export and choose JSON or CSV. The export includes tickets, comments, internal notes, contacts, organizations, users, and tags. Only one full export can run at a time.

## Getting the file

Large workspaces can take up to 24 hours to export. When the file is ready, Northstar Desk emails a download link to the person who started the export. The download link is valid for 72 hours.

## Attachments

Attachment files are not inside the export. Instead, the export lists a download URL for each attachment. Those attachment URLs expire 7 days after the export finishes, so download the attachments you need within that week.

## Exporting with the API

The API also has bulk export endpoints for tickets and contacts. They are limited to 10 requests per hour and need a key with the read scope or higher.
