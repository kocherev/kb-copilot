# Sample docs

These pages are original sample support docs for Northstar Desk, a fictional product. They were written for this repository and use the MIT license in the repository root `LICENSE`.

Pages under `community/` with `poisoned` in the file name are deliberate test pages. They contain prompt-injection text and false claims, and the evals check that they never become the cited answer to a normal question.

The PDF under `security/` is generated by `evals/scripts/make_pdf.py`. Run `uv run python evals/scripts/make_pdf.py` from the repository root to rebuild it.
